# Spatially resolved maternal and fetal cell contributions in Severe Preeclampsia 

Data processing and analysis scripts for the paper:  **Spatially resolved fetal and maternal cell contributions to severe preeclampsia across gestation**
DOI: 10.1126/sciadv.aed8964

## Repository contents

* `src`: contains scripts and notebooks used for single-cell analysis and spatial analysis
* `metadata`: contains metadata related to donor and cell annotations, colours and groupings.
* A frozen version of this repository can be found at: [![DOI](https://zenodo.org/badge/983378273.svg)](https://doi.org/10.5281/zenodo.19066215)

## Raw sequencing data 
Fastq files from single-cell and spatial data are deposited in the public database: `NCBI GEO GSE319236` 


## Single-cell and Spatial processed data 

* Seurat objects are deposited in Figshare: https://doi.org/10.6084/m9.figshare.31489183
